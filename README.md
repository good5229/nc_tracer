# NC Toolpath 3D Viewer

[공개 뷰어](https://good5229.github.io/nc_tracer/) · 로컬 NC/G-code 파일의 프로그램상 3축 경로를 확인하는 정적 웹앱입니다. 파일을 선택하거나 끌어 놓고, 텍스트를 붙여넣거나 내장 합성 예제 또는 LinuxCNC 공개 데모를 선택할 수 있습니다. LinuxCNC 데모는 공구 길이·반경이 0인 명시적 참조 설정으로 불러옵니다. 앞의 두 데모는 이 조건에서 경로를 표시하고, G70/G71 예제는 G71.1 황삭 경로를 표시하고 G71.2 코너 처리에서 중단됩니다. [검증 결과와 제한](demo/README.md)을 확인하세요. 이동 유형·공구별 필터와 거리 통계, 브라우저 메모리 내의 두 파일 행 비교를 제공합니다. `.nc`, `.ngc`, `.tap`, `.gcode`, `.txt` UTF-8 파일을 지원합니다.

선반 예제 공구표는 제한된 선분·원호 반경 보정과 G40 직선 이탈, 제한적 G70/G71 경로를 지원합니다. [참조 조건과 제한](demo/README.md)을 확인하세요.

선 두께와 점 밀도를 조절할 수 있습니다. 대량 경로는 여러 화면 프레임으로 나누어 표시하며, 표시가 끝난 뒤 다음 블록으로 진행하므로 선택한 재생 속도보다 느려질 수 있습니다. 겹치는 동일 선을 클릭하면 최초로 해당 선을 만든 블록을 선택합니다.

## 중요한 제한

G00/G01과 제한된 G02/G03 원호, G90/G91, G20/G21 및 축 생략을 해석합니다. 초기 위치와 단위 및 모드를 추측하지 않습니다. 검증 범위 밖의 원호, 매크로, 공구 보정, 좌표계, 사이클 등은 미지원이며 진단과 함께 해당 지점에서 해석을 중단합니다. 별도 NC 형상 예측은 선택한 파일에 고정 예제 원재료와 단일 수직 평엔드밀을 적용하며, 시작점과 좌표 오프셋을 예제 값으로 가정합니다. 지원되지 않는 명령은 형상 계산을 중단합니다. 1 mm 셀 중심 근사이며 실제 공구 보정, 선반, 홀더·고정구·설비와의 충돌 및 일반 파일의 목표 형상과 일치 여부를 계산하지 않으므로 이 화면만으로 실제 가공 가능 여부를 판정할 수 없습니다. [지원 범위](docs/gcode-support-matrix.md)를 확인하세요.

FANUC (일부 명령) 프로파일은 미확인 명령·공구 교환·원점 복귀의 이동을 표시하지 않고 이후 좌표가 다시 확정되면 원본 지령 좌표 구간을 별도로 표시합니다. `?`는 미확인 명령이나 생략된 이동을 뜻합니다. 해당 행을 선택하면 코드 목록 아래에서 이유를 확인할 수 있습니다. 단위가 선언되지 않으면 숫자를 변환하지 않고 ‘원본 단위 미확인’으로 표시합니다. 작업 좌표계와 회전 구간은 각각 선택해 보며, G68.2·B/C축 회전 변환 및 공구 길이 보정은 적용하지 않습니다. 원호가 불일치하거나 구멍 가공 사이클을 해석할 수 없으면 해당 이동을 생략하고 알립니다. 이 화면은 실제 장비 경로나 가공 가능성 판정이 아닙니다.

G68.2 FANUC 오일러 좌표 미리보기를 켜면, 같은 작업 좌표계로 변환된 회전 구간을 「함께 보기」로 겹쳐 볼 수 있습니다. 변환되지 않은 구간과 다른 작업 좌표계는 포함하지 않으며, 회전 이동이나 공구 보정이 검증된 결과는 아닙니다.

선택된 경로보다 앞에 `TN`, `TD`, `TR`이 포함된 주석이 있으면 가장 가까운 원본 주석을 함께 표시합니다. 이 주석은 공구표나 공구 길이 보정값으로 사용하지 않습니다.

NC 파일 열기로 개별 파일을 불러오거나 NC 폴더 열기로 폴더를 선택하고 그 안의 파일을 목록에서 불러올 수 있습니다. 확장자가 없는 NC 파일도 선택할 수 있습니다. 폴더 선택 기능은 브라우저의 폴더 선택 지원이 필요합니다. 폴더의 파일은 브라우저 메모리에서만 사용되며, 선택만으로 미지원 NC 명령이나 실제 기계 설정이 해석되는 것은 아닙니다.

선택 구간의 예시 가공 형상은 해당 좌표 구간의 직선·원호 절삭 경로를 감싸는 가상의 직육면체 소재와 경로 크기에 비례한 단일 수직 평엔드밀을 적용합니다. 3D 경로 오른쪽 위에서 제거된 부피를 “가공한 부품”이라는 추정 형상으로 기본 표시하고 전체 가로·세로·높이 범위를 볼 수 있으며, 확대하면 남은 소재와 같은 시점으로 분리해 비교하거나 각각 볼 수 있습니다. 예시 형상 왼쪽의 좌표축은 형상을 회전할 때 함께 움직이며 X·Y·Z의 양의 방향을 보여줍니다. 확대 화면에서 표면에 마우스를 올리거나 터치하면 표면 좌표와 격자로 연결된 제거 영역의 가로·세로·높이 범위를 볼 수 있습니다. 이 연결 영역은 실제 개별 부품이나 설계 치수를 뜻하지 않습니다. 확대 형상에서 면을 클릭하면 격자에서 연결된 같은 평면의 윤곽과 면이 뻗어 있는 축 방향 길이가 표시됩니다. 이는 격자 면의 근사 범위이며 설계상의 면 치수는 아닙니다. 팝업에서 선택한 격자의 가장 깊은 예시 경로에 해당하는 NC 행과 3D 경로를 열 수 있습니다. 여러 경로가 겹칠 수 있어 대표 경로 한 개만 연결합니다. 확인이 필요한 NC 항목은 3D 경로 아래 목록에서 열 수 있으며, 위치를 모르는 항목은 형상에 임의로 배치하지 않습니다. 재생 시 현재 블록과 코드 행을 함께 표시합니다. 제거된 영역은 가상 소재에서 깎인 부피이며 실제로 한 덩어리로 분리된 제품을 뜻하지 않습니다. 높이 격자는 최대 96×96칸이며 미확인 단위는 mm로 가정해 표시합니다. 작업 좌표계·회전 구간은 합치지 않고 드릴·탭·선반 나사 사이클, 급속 이동, 실제 공구 보정과 측면·하부 절삭은 계산하지 않습니다. 단일 소재에서 여러 면을 가공한 실제 결과나 충돌·가공 가능성을 판정하는 결과가 아닙니다.

일반 프로파일에서 FANUC 포스트프로세서 표기 또는 해당 형식의 회전 좌표 명령이 확인된 파일을 열면 FANUC 형식 좌표 미리보기를 자동 선택합니다. 이는 실제 컨트롤러 판정이 아니며, 프로파일을 직접 바꾸면 현재 파일을 즉시 다시 해석합니다.

파일은 브라우저에서 처리하며 서버에 보내지 않습니다. 사용자가 직접 저장한 NC 파일 최대 3개는 해당 브라우저의 IndexedDB에 보관되어 다시 열거나 삭제할 수 있습니다. 저장하지 않은 파일은 새로고침하면 제거됩니다. 저장한 파일도 사이트 데이터 삭제, 시크릿 모드 종료 또는 브라우저 저장 공간 정리 시 사라질 수 있으므로 원본을 별도로 보관해야 합니다. 로컬 주소와 GitHub Pages는 서로 다른 저장 공간을 사용합니다. GitHub Pages 접속 기록은 플랫폼이 관리합니다. 첫 방문에는 네트워크가 필요하며 오프라인 사용은 보장하지 않습니다.

## 실행 및 검증

Node.js 22.12 이상(또는 24)에서 실행합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

GitHub Actions가 main 브랜치에서 빌드와 검사를 거쳐 GitHub Pages에 배포합니다. Vite base는 `/nc_tracer/`입니다. [공개 테스트 자료와 출처](docs/sample-sources.md), [검증 계획](docs/test-plan.md), [배포 체크리스트](docs/release-checklist.md)를 참고하세요. 개인 또는 회사의 실제 NC 파일을 공개 저장소나 CI에 올리지 마세요.
