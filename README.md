# NC Toolpath 3D Viewer

[공개 뷰어](https://good5229.github.io/nc_tracer/) · 로컬 NC/G-code 파일의 프로그램상 3축 경로를 확인하는 정적 웹앱입니다. 파일을 선택하거나 끌어 놓고, 텍스트를 붙여넣거나 내장 합성 예제 또는 LinuxCNC 공개 데모를 선택할 수 있습니다. LinuxCNC 데모는 공구 길이·반경이 0인 명시적 참조 설정으로 불러옵니다. 앞의 두 데모는 이 조건에서 경로를 표시하고, G70/G71 예제는 G71.1 황삭 경로를 표시하고 G71.2 코너 처리에서 중단됩니다. [검증 결과와 제한](demo/README.md)을 확인하세요. 이동 유형·공구별 필터와 거리 통계, 브라우저 메모리 내의 두 파일 행 비교를 제공합니다. `.nc`, `.ngc`, `.tap`, `.gcode`, `.txt` UTF-8 파일을 지원합니다.

밀링 데모는 별도로 LinuxCNC 2.9.4가 지름 1.5875mm 공구로 생성한 저장된 보정 경로와 예제 소재를 이용해 0.5mm 격자 형상을 표시할 수 있습니다. 이는 해당 원본과 고정 설정에 한정되며 범용 공구 보정 해석은 아닙니다. 선반 예제 공구표는 제한된 선분·원호 반경 보정과 G40 직선 이탈, 보정이 꺼진 제한적 G70/G71 및 제한적 다중 패스 보정 G70을 지원합니다. 원형 공구 끝 또는 가상 인서트 단면과 원통 예제 소재의 축 대칭 제거를 0.2mm 격자로 보여 줍니다. 외경 G76은 가상의 60도 나사 공구와 48개 회전 각도 격자로 근사합니다. 실제 인서트 규격·홀더·스핀들 가감속은 모델링하지 않습니다. 두 선반 데모는 현재 실제 공구 조건에서 중단돼 완성 형상을 지원하지 않습니다. [참조 조건과 제한](demo/README.md)을 확인하세요.

선 두께와 점 밀도를 조절할 수 있습니다. 대량 경로는 여러 화면 프레임으로 나누어 표시하며, 표시가 끝난 뒤 다음 블록으로 진행하므로 선택한 재생 속도보다 느려질 수 있습니다. 겹치는 동일 선을 클릭하면 최초로 해당 선을 만든 블록을 선택합니다.

## 중요한 제한

G00/G01과 제한된 G02/G03 원호, G90/G91, G20/G21 및 축 생략을 해석합니다. 초기 위치와 단위 및 모드를 추측하지 않습니다. 검증 범위 밖의 원호, 매크로, 공구 보정, 좌표계, 사이클 등은 미지원이며 진단과 함께 해당 지점에서 해석을 중단합니다. 별도의 고정된 밀링 예제는 1 mm 격자로 원재료 제거와 목표 홈의 차이, 급속 이동의 원재료 접촉을 근사합니다. 별도 NC 형상 예측은 선택한 파일에 고정 예제 원재료와 단일 수직 평엔드밀을 적용하며, 시작점과 좌표 오프셋을 예제 값으로 가정합니다. 지원되지 않는 명령은 형상 계산을 중단합니다. 1 mm 셀 중심 근사이며 실제 공구 보정, 선반, 홀더·고정구·설비와의 충돌 및 일반 파일의 목표 형상과 일치 여부를 계산하지 않으므로 이 화면만으로 실제 가공 가능 여부를 판정할 수 없습니다. [지원 범위](docs/gcode-support-matrix.md)를 확인하세요.

파일 내용과 이름 및 좌표는 브라우저 메모리에서만 처리하고 애플리케이션이 서버에 보내거나 영구 저장하지 않습니다. 탭을 닫거나 새로고침하면 제거됩니다. GitHub Pages 접속 기록은 플랫폼이 관리합니다. 첫 방문에는 네트워크가 필요하며 오프라인 사용은 보장하지 않습니다.

## 실행 및 검증

Node.js 22.12 이상(또는 24)에서 실행합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

GitHub Actions가 main 브랜치에서 빌드와 검사를 거쳐 GitHub Pages에 배포합니다. Vite base는 `/nc_tracer/`입니다. [공개 테스트 자료와 출처](docs/sample-sources.md), [검증 계획](docs/test-plan.md), [배포 체크리스트](docs/release-checklist.md)를 참고하세요. 개인 또는 회사의 실제 NC 파일을 공개 저장소나 CI에 올리지 마세요.
