# 공개 테스트 자료: LinuxCNC

LinuxCNC 프로젝트의 공개 예제에서 2026-10-27에 수집했습니다. 원본 저장소의 GPL-2.0 라이선스 원문을 `COPYING`에 보관합니다. 원본: https://github.com/LinuxCNC/linuxcnc/tree/c9a5a0a5034177c8db64cb44abf14d4f2eb166f7/nc_files

- `3dtest.ngc`: 여러 평면의 원호 포함. 현재 뷰어에서 첫 원호에서 중단되는지 확인합니다.
- `arcspiral.ngc`: 원호와 컨트롤러 명령 포함. 미지원 진단 확인용입니다.
- `increment.ngc`: 매크로/서브루틴 포함. 확정 경로로 해석하지 않는지 확인합니다.

이 자료는 제조 현장에서 실행하기 위한 프로그램이 아닙니다. 실제 장비에 사용하지 마세요. 기본 뷰어 기능은 앱 내부의 별도 합성 예제로도 시험할 수 있습니다.
