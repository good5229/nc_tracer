# G-code 지원 프로파일 — conservative-p1

이 문서는 제한적인 3축 G-code 해석 계약이다. 범용 CNC 컨트롤러 호환을 주장하지 않는다. 단위·좌표·거리 모드·이동 모드는 기본 unknown이며 사용자 명시 입력 또는 해당 G 코드로만 확정한다. 좌표는 내부적으로 mm, 숫자는 유한한 십진수만 허용한다.

| 문법 | P0 정책 |
| --- | --- |
| G0/G00, G1/G01 | 모달 급속/직선, 완전한 시작·끝 좌표일 때만 3D 선 생성 |
| G20/G21 | inch/mm; inch 좌표와 feed ×25.4로 내부 mm 환산 |
| G90/G91 | 절대/증분; unknown은 0으로 취급하지 않음 |
| X/Y/Z | 선택 축 갱신, 생략 축 보존; G91 unknown 축은 계속 unknown |
| G17/G18/G19 | plane 상태 추적; P0 직선 기하학에는 영향 없음 |
| F/S/T | 숫자 메타데이터만 추적; 실제 feed 시간·스핀들·공구 보정 효과 주장 없음 |
| N 정수 | 선택 block ID 문자열; 반복 가능, 원본 행 번호와 별개 |
| M2/M02/M30 | 프로그램 종료; 이후 비어 있지 않은 코드는 실행 경로에 포함하지 않고 진단 |
| 괄호 주석 / ; 이후 | 실행 문법과 분리. 괄호 불균형·중첩은 INVALID |
| % 단독 행 | 프로그램 경계 표식; 이동 없음 |
| G02/G03 및 I/J/K/R | G17/G18/G19 명시 필요; IJK는 시작점 기준 중심 오프셋, signed R은 양수 minor/음수 major. IJK 완전원 및 축 보간 지원. 혼합 R/IJK, 반지름 불일치, R 완전원 및 180도 모호성은 INVALID |
| G54–G59, G53, G92, G28, G41/G42/G43 및 해제 명령 | 좌표계·보정 의미 미확정, 미지원 경계에서 정지 |
| 사이클, 매크로, #, [], IF/GOTO, 서브프로그램, A/B/C/U/V/W | 미지원 경계에서 정지 |
| 기타 G/M/주소, block-delete / | 검증되지 않은 구문, 미지원 경계에서 정지 |

## 상태 전이

1. 블록의 전체 토큰/상충을 먼저 검증한 후 상태에 반영한다. 해당 블록의 단위·거리 모드가 같은 블록의 축 값에 적용된다.
2. G90은 알려진 단위에서 명시 축의 절대값을 확정한다. 생략 축은 그대로 유지한다. G91은 알려진 단위·현재 축에 한해 누적한다.
3. 모드/단위 미확정 이동은 정상 선으로 출력하지 않는다. 그 이동의 좌표는 보수적으로 unknown 처리하고 후속 명시 절대좌표에서만 복구한다.
4. 시작이 미확정이어도 G90 X/Y/Z 전체 지정으로 끝 위치를 확정할 수 있다. 이 블록은 위치 확정 역할이며 미확정 시작점을 잇는 선을 생성하지 않는다.
5. 검증 범위 밖 원호·보정·좌표계·알 수 없는 코드의 영향이 불명확하면 해당 블록을 원자적으로 거부하고 이후 실행 해석을 멈춘다. 앞의 확정 경로만 유지하며 뒤를 임의 복구하지 않는다.
6. 중복 축/숫자 오류/서로 다른 같은 모달 그룹 명령/불균형 주석/비유한 수/계산 overflow는 INVALID. 잘못된 블록의 일부 좌표를 적용하지 않는다.

## 결과 분류

- SUPPORTED: 처리된 코드가 모두 지원 범위에 있고 모든 요청 이동을 확정 가능. 이동 없는 빈 입력은 별도 빈 상태로 안내한다.
- PARTIAL: 미확정 초기상태 또는 미지원 경계로 일부 이동을 표시할 수 없다. 확정 prefix/구간만 표시하고 경고한다.
- UNSUPPORTED: 미지원 경계로 표시 가능한 이동이 전혀 없다.
- INVALID: 문법/숫자 오류; 앞의 검증된 prefix가 있으면 오류 표시와 함께만 제공한다. 오류를 정상 완료로 표시하지 않는다.

원본 행은 1부터 시작하며 CRLF/LF를 지원한다. UTF-8 BOM을 제거하되 원문 행 매핑은 유지한다. 빈 행/주석도 행 번호에 포함한다. 행→구간은 1:N 배열 계약이고 현재 구현은 모션 블록마다 하나이며 원호의 분할점은 해당 블록에 포함된다. 모든 renderer 입력 좌표는 finite여야 한다.

## 원호 표시와 제한

G17은 XY, G18은 ZX, G19는 YZ의 오른손 좌표계 방향을 사용한다. G90.1/G91.1 등 중심의 모달 절대 지정은 지원하지 않는다. 원호는 한 모션 블록에 저장하며 최대 5도 및 기하학상 0.01 mm 현 오차를 기준으로 분할한다. 100,000개 선분을 넘어야 하는 원호는 추측하지 않고 INVALID로 중단한다. 원호 분할점은 전체 프로그램에서 최대 1,000,000개까지 허용한다. 표시용 Float32 변환의 3차원 위치 오차가 0.01 mm를 넘는 좌표는 진단하고 해석을 중단한다. 이 검사는 GPU 변환 단계 전체의 정밀도 보장은 아니다.
