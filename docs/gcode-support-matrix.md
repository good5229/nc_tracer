# G-code 지원 프로파일 — conservative-p1

이 문서는 제한적인 3축 G-code 해석 계약이다. 범용 CNC 컨트롤러 호환을 주장하지 않는다. 단위·좌표·거리 모드·이동 모드는 기본 unknown이며 사용자 명시 입력 또는 해당 G 코드로만 확정한다. 좌표는 내부적으로 mm, 숫자는 유한한 십진수만 허용한다.

| 문법 | P0 정책 |
| --- | --- |
| G0/G00, G1/G01 | 모달 급속/직선, 완전한 시작·끝 좌표일 때만 3D 선 생성 |
| G20/G21 | inch/mm; inch 좌표와 feed ×25.4로 내부 mm 환산 |
| G90/G91 | 절대/증분; unknown은 0으로 취급하지 않음 |
| X/Y/Z | 선택 축 갱신, 생략 축 보존; G91 unknown 축은 계속 unknown |
| G17/G18/G19 | plane 상태 추적; P0 직선 기하학에는 영향 없음 |
| F/S/T | 숫자 메타데이터만 추적; 실제 feed 시간·스핀들·공구 보정 효과 주장 없음 |
| N 정수 | 선택 block ID 문자열; 반복 가능, 원본 행 번호와 별개 |
| M2/M02/M30 | 프로그램 종료; 이후 비어 있지 않은 코드는 실행 경로에 포함하지 않고 진단 |
| 괄호 주석 / ; 이후 | 실행 문법과 분리. 괄호 불균형·중첩은 INVALID |
| % 단독 행 | 프로그램 경계 표식; 이동 없음 |
| G02/G03 및 I/J/K/R | G17/G18/G19 명시 필요; IJK는 시작점 기준 중심 오프셋, signed R은 양수 minor/음수 major. IJK 완전원 및 축 보간 지원. 혼합 R/IJK, 반지름 불일치, R 완전원은 INVALID; R 반원은 유일한 중심으로 처리 |
| G54–G59, G53, G92, G28, G41/G42/G43 및 해제 명령 | 좌표계·보정 의미 미확정, 미지원 경계에서 정지 |
| 사이클, 매크로, #, [], IF/GOTO, 서브프로그램, A/B/C/U/V/W | 미지원 경계에서 정지 |
| 기타 G/M/주소, block-delete / | 검증되지 않은 구문, 미지원 경계에서 정지 |

## 상태 전이

1. 블록의 전체 토큰/상충을 먼저 검증한 후 상태에 반영한다. 해당 블록의 단위·거리 모드가 같은 블록의 축 값에 적용된다.
2. G90은 알려진 단위에서 명시 축의 절대값을 확정한다. 생략 축은 그대로 유지한다. G91은 알려진 단위·현재 축에 한해 누적한다.
3. 모드/단위 미확정 이동은 정상 선으로 출력하지 않는다. 그 이동의 좌표를 unknown 처리하고 해당 지점에서 해석을 중단한다.
4. 시작이 미확정이어도 G90 X/Y/Z 전체 지정으로 끝 위치를 확정할 수 있다. 이 블록은 위치 확정 역할이며 미확정 시작점을 잇는 선을 생성하지 않는다.
5. 검증 범위 밖 원호·보정·좌표계·알 수 없는 코드의 영향이 불명확하면 해당 블록을 원자적으로 거부하고 이후 실행 해석을 멈춘다. 앞의 확정 경로만 유지하며 뒤를 임의 복구하지 않는다.
6. 중복 축/숫자 오류/서로 다른 같은 모달 그룹 명령/불균형 주석/비유한 수/계산 overflow는 INVALID. 잘못된 블록의 일부 좌표를 적용하지 않는다.

## 결과 분류

- SUPPORTED: 처리된 코드가 모두 지원 범위에 있고 모든 요청 이동을 확정 가능. 이동 없는 빈 입력은 별도 빈 상태로 안내한다.
- PARTIAL: 미확정 초기상태 또는 미지원 경계로 일부 이동을 표시할 수 없다. 확정 prefix/구간만 표시하고 경고한다.
- UNSUPPORTED: 미지원 경계로 표시 가능한 이동이 전혀 없다.
- INVALID: 문법/숫자 오류; 앞의 검증된 prefix가 있으면 오류 표시와 함께만 제공한다. 오류를 정상 완료로 표시하지 않는다.

원본 행은 1부터 시작하며 CRLF/LF를 지원한다. UTF-8 BOM을 제거하되 원문 행 매핑은 유지한다. 빈 행/주석도 행 번호에 포함한다. 행→구간은 1:N 배열 계약이고 현재 구현은 모션 블록마다 하나이며 원호의 분할점은 해당 블록에 포함된다. 모든 renderer 입력 좌표는 finite여야 한다.

## 원호 표시와 제한

G17은 XY, G18은 ZX, G19는 YZ의 오른손 좌표계 방향을 사용한다. G90.1/G91.1 등 중심의 모달 절대 지정은 지원하지 않는다. 원호는 한 모션 블록에 저장하며 최대 5도 및 기하학상 0.01 mm 현 오차를 기준으로 분할한다. 100,000개 선분을 넘어야 하는 원호는 추측하지 않고 INVALID로 중단한다. 원호 분할점은 전체 프로그램에서 최대 1,000,000개까지 허용한다. 표시용 Float32 변환의 3차원 위치 오차가 0.01 mm를 넘는 좌표는 진단하고 해석을 중단한다. 이 검사는 GPU 변환 단계 전체의 정밀도 보장은 아니다.

## LinuxCNC 부분 프로파일

사용자가 LinuxCNC를 선택했을 때 G61/G61.1/G64 경로 제어, G64의 P/Q 허용 오차, G4 P 정지 및 M3/M4/M5 스핀들 명령을 추가로 인식한다. G64 P/Q와 같은 블록에 이동 좌표를 함께 지정하는 경우는 지원하지 않는다. 이 명령을 허용해도 표시 경로는 블록의 지령 경로이며 G64 블렌딩을 포함한 실제 기계 경로는 계산하지 않는다. 일반 LinuxCNC 프로파일에서 M6 공구 교환, 공구 보정, 좌표계, G70/G71.2 및 일부 매크로 구문은 여전히 미지원이다. 일반 프로파일의 동작은 바뀌지 않는다. 선택한 프로파일은 다음 해석에 적용된다. LinuxCNC 명령의 의미는 [공식 G-code 문서](https://linuxcnc.org/docs/html/gcode/g-code.html)를 기준으로 한다.

LinuxCNC 프로파일은 수치 O-코드 서브루틴과 제한된 변수·표현식·while 반복을 실행 순서로 펼친다. 반복 횟수·호출 깊이·실행 단계에 상한을 두고 미지원 또는 오류가 있으면 기존 보수적 경계에서 정지한다. G76은 공구 반경 보정이 꺼진 G8 반경 모드, G18, 확정된 단위·위치·거리 모드와 회전 중인 스핀들이 있을 때만 나사 절삭을 직선 이동으로 전개하며, 각 이동을 원래 G76 행에 연결한다. 경로 전개는 스핀들 동기 구간과 예제 위상 정보를 보존한다. 실제 가감속은 계산하지 않는다.

내장 LinuxCNC 데모는 시작점 XYZ=0, G90/G8, G54=0, 공구 반경·길이=0, 위치 변경 없는 M6의 명시적 가상 설정을 사용한다. 이 설정에서 G92/G92.1을 고정 참조 좌표로 변환하고, G41/G42는 0반경이므로 경로를 이동시키지 않는다. 실제 비영 공구 보정이나 임의 공구표·작업 좌표계는 지원하지 않으며, 데모 설정을 실제 장비에 적용한 결과로 해석하지 않는다.

점 공구 참조 설정의 G71.1은 XZ·G8·G90·mm 숫자 윤곽으로 한정하며, 직선·원호의 접점 간격이 0.00001mm 이하이면 LinuxCNC 2.9.4의 생성 경로 계산 방식으로 재시도하며, 최초 간격이 이보다 크거나 중간 생성 윤곽의 간격이 0.001mm를 넘으면 중단한다. 이는 원본 NC 좌표를 수정하는 기능이 아니다. 같은 가상 설정의 G71.2는 XZ 숫자 직선·원호 윤곽, D 여유량, I/R 0.01mm 이상, 100개 이하 윤곽을 제한적으로 지원한다. A/C 코너는 아직 지원하지 않으며 교점이 불명확하면 중단한다. G70은 같은 설정에서 A/C 코너가 없는 XZ 숫자 직선·원호 윤곽과 D/E 여유량, 최대 100 패스를 지원한다. 좌표 방향 전환이나 검증 불가능한 접점은 중단한다. 명시적 선반 예제 공구표에서도 공구를 장착하고 반경 보정이 꺼진 상태라면 동일한 제한으로 G70/G71 경로를 계산하며 해당 공구로 경로를 해석한다. 반경 보정을 켠 직후 G70은 보정 가능한 윤곽과 패스 간 큐가 지원 범위에 있을 때 D/E 여유량 및 다중 패스를 제한적으로 지원한다. G40 직후라면 사이클 전에 직선 이탈을 완료해야 한다. LinuxCNC 2.9.4는 보정이 켜진 G71을 거부한다. 검증 범위 밖의 보정 G70 큐 전환, 검증 범위 밖의 원호 간 연결과 공구표 X/Z의 비영 오프셋, 다른 버전과의 동등성은 지원하지 않는다.

G71.2의 제한된 직선 윤곽은 [LinuxCNC 2.9.4 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40462524673)에서 단순·단일 홈·이중 홈·경사 윤곽을 비교했다. G70의 단일·다중 패스 참조는 [별도 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40462562108)과, 원호와 여유량은 [원호 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40463917805)과 비교했다. 이는 명시된 점 공구 및 예제 좌표 설정에 대한 경로 검증이며 실제 공구 보정이나 완성 형상 검증이 아니다.

선반 예제 공구표의 반경 보정은 LinuxCNC 2.9.4의 [보정 참조 경로](https://github.com/good5229/nc_tracer/actions/runs/40464949783)와 선분, 접선 원호 및 G40 이탈을 대조했다. G41과 G42의 비접선 볼록 선분·원호 연결은 각각 [G41 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40507362704)과 [G42 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40507813406)을 대조했다. 오목 선분·원호 연결은 [오목 접점 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40510000414), 오목 원호 간 연결은 [원호 간 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40510388560)과 대조했다. 보정 중 G90/G91 전환도 제한적으로 지원한다. 직선 윤곽의 단일 패스는 [G70 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40480010891)과, 다중 패스와 여유량은 [다중 패스 참조 실행](https://github.com/good5229/nc_tracer/actions/runs/40509298848)과 비교했다. 명시적 예제 공구표는 T1/T2/T4/T9/T10의 직경 0.4mm, 방향 2, X/Z 길이 0과 고정 공구 교환을 가정하며 실제 기계의 값이 아니다.



## 제한적 FANUC 원본 좌표 미리보기

FANUC 프로파일은 프로그램에 적힌 XYZ 지령을 원본 작업 좌표로 표시한다. `N`은 프로그램 내 블록을 식별하는 번호로 취급하며, 프로그램 종료 뒤 번호만 적힌 행과 N 번호가 붙은 `%` 종료 표시는 추가 이동으로 경고하지 않는다. 이는 장비가 해당 표기법을 허용하는지의 판정은 아니다. 단위가 없는 파일은 수치를 변환하지 않고 `원본 단위 미확인`으로 표시한다. 서로 다른 G54~G59 작업 좌표계 및 회전 구간은 별도로 선택한다. 작업 좌표계가 명시되지 않은 경우에도 회전 전후 구간을 분리하고 좌표계를 미확인으로 표시한다. 좌표계 원점의 실제 상대 위치나 B/C축 기계 회전, 공구 길이 보정은 계산하지 않는다. 회전 지령으로 시작된 구간은 선택 목록과 구간 정보에 원본 축·각도, 지령 행과 좌표 모드를 표시한다. 이는 실제 축 위치가 아니다. G00/G01과 G90/G91이 회전축과 함께 지정된 경우에도 해당 동시 이동은 생략하고, 이후 좌표가 다시 확인되면 별도 구간으로 표시한다. 선택 사항인 G68.2 FANUC 오일러 좌표 미리보기는 명시된 I/J/K 및 X/Y/Z(생략된 원점 축은 0)를 이용해 Z-X-Z 회전으로 프로그램 좌표를 작업 좌표로 변환한다. 이는 실제 장비의 B/C축 운동학이나 회전축 이동 계산이 아니다. 다른 P 모드와 불완전한 G68.2는 변환하지 않는다.

G28 원점 복귀·G53 기계 좌표 이동·M6 교환, 미확인 M 코드 및 G05/G5.1 설정은 해당 이동을 생략하고 좌표를 미확정으로 처리한다. 이후 프로그램상 좌표가 다시 확정되면 별도 구간을 표시한다. 미확인 M 코드 또는 G05/G5.1 이후에도 앞서 명시된 G17/G18/G19, G90/G91과 이동 모드를 프로그램 지령 기준으로 유지한다. 이는 장비별 명령이 실제 모달 상태에 영향을 주지 않는다는 판정이 아니며 해당 경계에 경고한다. G43의 H 번호를 추적해 선택 구간에 표시하고 G49에서 해제한다. 장비의 보정값은 알 수 없으므로 적용하지 않으며 보정이 걸리는 이동은 생략한다. [FANUC 0i-D 설명서](https://cncedu.hu/wp-content/uploads/2020/10/Fanuc-0i-Mate-MDUsers-Manual.pdf)의 고정 사이클 규칙에 따라 G83/G84만 있는 행은 사이클을 선택하되 구멍을 추가하지 않고, 이후 좌표·R·깊이와 필요한 값이 확인되면 표시한다. 진행 중 좌표·R 지령 없이 이송 속도나 복귀 방식만 바꾸는 블록 역시 구멍을 추가하지 않는다. G83/G84는 XY 평면·절대 좌표·구멍 위치 및 R/Z가 확인되고 G83에서는 Q도 확인될 때만 R면부터 목표 Z까지의 깊이 범위를 직선으로 표시하고 `?`를 붙인다. G83은 최종 깊이에서 R면까지의 복귀와 시작 높이가 확인된 R면 접근 및 G98 복귀도 지령 미리보기로 표시한다. 반복 절삭과 중간 후퇴·재진입은 장비 설정을 몰라 표시하지 않는다. 여러 차례의 절삭과 후퇴 경로를 뜻하지 않으며 이동 거리 합계에도 포함하지 않는다. M29는 동기 탭 지령으로 표시하되 기계 동작은 확정하지 않는다. G84에서 Q가 없으면 R~Z 진입과 R 복귀를 별도 구간으로 표시한다. 양의 Q가 있으면 FANUC의 Q 절입 깊이를 기준으로 깊어지는 구간과 마지막 R 복귀를 표시한다. 중간 후퇴와 재진입은 장비 설정에 의존하므로 생략하며, 절입 횟수가 1,000회를 넘으면 깊이 범위만 표시한다. G84에서 이전 지령 높이가 확인되고 R보다 높으면 R면까지의 급속 접근을 지령 미리보기로 표시한다. 반복 구멍은 직전 G98/G99 복귀 높이가 확인될 때만 접근을 표시한다. M29 이후 실제 위치는 확인되지 않는다. G98/G99는 사이클보다 앞선 별도 행에서도 기억하며, G98이 명시되어 있고 최초 지령 시작 높이가 R보다 높으면 R에서 그 높이로의 급속 복귀도 지령 미리보기에 추가한다. G99 또는 시작 높이가 불명확할 때에는 그 구간을 만들지 않는다. G94 이송과 스핀들 속도가 명시된 경우 F/S를 지령상 피치로 표시하되 실제 나사 형상이나 동기 회전은 계산하지 않는다. 조건이 확인되지 않는 사이클은 표시하지 않는다. G80 또는 별도 행의 G00~G03으로 사이클을 해제한 뒤에는 확인되지 않은 종료 위치를 끊고 좌표가 다시 확인되면 재개한다. 원호 평면이나 시작점이 불명확한 경우 원호는 생략하되 절대 좌표로 명시된 끝점은 이후 지령 좌표 미리보기에 사용한다. 원호의 시작점과 끝점에서 계산한 반경 차이가 내부 좌표 기준 0.002 이하인 경우 양쪽 지령 좌표를 보존하며 반경을 점진적으로 바꾼 표시용 근사선을 그리고 `?`로 표시한다. 선택한 행의 진단에 계산된 반경 차이를 표시한다. 단위가 확인되지 않은 경우 기준도 원본 숫자 단위이다. 0.002는 이 뷰어의 표시 기준이며 장비의 원호 허용오차가 아니다. 차이가 더 크거나 원호 평면·중심을 확인할 수 없으면 해당 이동을 생략한다. 미확인 동작 이후 프로그램이 실제로 계속 실행되는지, 표시된 좌표가 실제 공구 위치와 일치하는지는 확인되지 않는다.

NX CAM의 출력은 기계별 포스트프로세서에 의해 만들어지므로 NX 파일을 단일 컨트롤러 형식으로 취급하지 않는다. [Siemens NX 후처리 설명](https://www.siemens.com/en-us/products/nx-manufacturing/cam-software/postprocessing-simulation/), [LinuxCNC 원호 반올림 설명](https://linuxcnc.org/docs/html/gcode/g-code.html)을 참고했으며 LinuxCNC의 허용오차를 FANUC 기계의 허용오차로 취급하지 않는다.

G68.2 오일러 변환 순서는 [FANUC 0i-F 작업자 설명서 5.7.1.1](https://www.drivesul.com.br/template/imagens/manuais/manuais-fanuc/fanuc-series-0i-model-f/FANUC%20Series%200i%20MODEL%20F%20-%20OPERATOR_S%20MANUAL%20-%20Machining%20Center%20System.pdf)을 기준으로 한다. G84 Q의 중간 복귀는 [FANUC 0i-F 작업자 설명서 5.1.8](https://www.drivesul.com.br/template/imagens/manuais/manuais-fanuc/fanuc-series-0i-model-f/FANUC%20Series%200i%20MODEL%20F%20-%20OPERATOR_S%20MANUAL%20-%20Machining%20Center%20System.pdf)에서 매개변수 5104#6, 5200#5, 5213에 따라 달라진다. G84는 [Haas G84 설명](https://haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dmill.value%3DG84)의 깊이 지령을 참고하며 다른 컨트롤러와 장비의 동작까지 동일하다고 가정하지 않는다.

Q 탭 중간 후퇴는 [FANUC 0i-D 설명서 5.2.3](https://web.chungbuk.ac.kr/~kwjeong/lectures/teacher1class_automation/FANUC_0i%28VMC%29_OPERATORS_MANUAL.pdf)에서 설정 5200과 5213에 따라 달라진다. 절입 구간 표시도 FANUC Q 의미를 적용한 지령 미리보기이며 특정 장비 설정의 검증이 아니다.

NX CAM의 NC 출력은 장비별 후처리 설정에 영향을 받는다. [Siemens NX CAM 후처리 설명](https://www.siemens.com/en-us/products/nx-manufacturing/cam-software/postprocessing-simulation/)을 참고하며 NX로 생성됐다는 사실만으로 장비의 회전축 구조를 확정하지 않는다. 공구 길이 H는 [Haas 공구 보정 설명](https://haascnc.com/service/online-operator-s-manuals/mill-operator-s-manual/mill---part-setup.html/1000.html)처럼 보정표의 항목을 가리키며 장비의 실제 값은 파일만으로 확인할 수 없다.
