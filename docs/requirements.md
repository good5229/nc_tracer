# 요구사항 — NC Toolpath 3D Viewer

승인 범위: P0 보수적 3축 지령 경로 뷰어. 문서 승인은 구현·성능·공개 배포 완료 승인이 아니다. 실제 소재 제거, 충돌 판정, 설비 제어 및 가공 안전성 보증을 제공하지 않는다.

## 사용자 결과와 수용 기준

| ID | 요구 | 수용 기준 |
| --- | --- | --- |
| R01 | 로컬 입력 | .nc/.tap/.gcode/.txt 선택, drop, 붙여넣기를 브라우저에서 읽고 Worker에서 파싱한다. UTF-8/BOM 지원, 잘못된 인코딩 명시 진단. |
| R02 | 보수적 경로 | G00/G01, G20/G21, G90/G91을 지원하고 초기 좌표·모드를 임의 가정하지 않는다. 미지원 구문 뒤 경로는 생성하지 않는다. |
| R03 | 3D 탐색 | 점/선, XYZ 축/격자, 회전·줌·이동, XY/XZ/YZ, 원점/전체 맞춤 및 급속/절삭 표시 토글. 문자 범례 병기. |
| R04 | 순서 탐색 | 이전/다음, 처음, 재생/일시정지, 속도, 모션 블록 기반 슬라이더. 재생은 순서 데모이며 실제 가공 시간이나 급속 속도로 주장하지 않는다. |
| R05 | 원문 연계 | 원문 행 선택→해당 경로 강조·재생 이동; 경로 선택→행·N·원문·시작/끝·유형 표시. 반복 N 허용, 행 번호와 N 분리. |
| R06 | 불확실성 | SUPPORTED/PARTIAL/UNSUPPORTED/INVALID, 행별 사유 및 경고, 확정 구간 수 표시. 미확정 초기 위치 사용자 입력 제공. |
| R07 | 교체 | 새 파일 시 이전 경로, 선택, 재생, 경고 및 지연 Worker 응답 제거. |
| R08 | 기밀성 | 파일명/원문/좌표를 네트워크 전송 또는 브라우저 영구 저장하지 않는다. 안전한 텍스트 렌더링. |
| R09 | 배포 | 동일 정적 빌드를 GitHub Pages 하위 경로에서 제공하고 공개 URL 기본 흐름 검증. |
| R10 | 접근성/성능 | 키보드로 입력·재생·행 탐색 가능, 명확한 focus/label/오류. 1k/10k/100k 합성 입력의 파싱·상호작용·메모리 측정. |

## 단계 범위

- P0: 위 요구 전체와 보수적 직선 파서, Web Worker, 자동 검증/Pages 배포.
- P1: 별도 사양과 기하학 정답 승인 후 G02/G03·IJK/R·평면별 원호, 통계·공구 필터·대용량 최적화·메모리 내 비교.
- P2: 별도 요청/검토 이후 접근성 확장 또는 명시적 오프라인/PWA 설계.
- 제외: 편집/다운로드/백업, 계정/DB/API 서버, CNC 제어, 실제 가공물·충돌·4/5축 기구학, 외부 LLM/분석 SDK.

## 화면 정보 구조

상단 입력/상태/도움말, 왼쪽 원문·검색·진단, 중앙 3D, 하단 순서 재생·현재 좌표, 정보 영역 파일 크기·블록 수·구간 수·경고·단위/프로파일. 좁은 화면은 세로 배치하며 조작을 가리지 않는다.

필수 문구: “실제 가공 형상/충돌 검증 결과가 아님”, “파일은 이 브라우저에서 처리되며 애플리케이션 서버에 업로드하지 않습니다.” GitHub Pages 접속 로그는 호스팅 플랫폼이 관리한다. “절대 유출 불가”는 주장하지 않는다.

초기 설정은 파일별 메모리에만 적용한다. 첫 방문은 네트워크가 필요하다. 오프라인 보장은 별도 시험 전에는 하지 않는다. 실제 회사 NC 원본은 저장소·CI·원격 로그에 포함하지 않는다.
